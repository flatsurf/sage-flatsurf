# Hyperbolic Surfaces

A hyperbolic cone surface is glued from compact polygons of the hyperbolic
plane by orientation preserving isometries. Its vertices are cone points, it
may have a geodesic boundary, and it is defined over a single field, its base
ring.

Hyperbolic surfaces are built like flat surfaces, from pre-built collections
or by gluing polygons, and share many methods with them (angles, area,
orbifold points, holonomy); this is described in
[Defining Surfaces](./defining_surfaces). This page is about what is specific
to the hyperbolic setting.

## Polygons in the Klein model

Points of the hyperbolic plane are given here by their coordinates in the
Klein model, the unit disk in which hyperbolic geodesics are straight
segments. A polygon is given by its vertices, in counterclockwise order:

```{code-cell}
from sage.all import QQ

from flatsurf import HyperbolicPlane

H = HyperbolicPlane(QQ)
P = H.polygon(
    vertices=[
        H.point(0, 0, model="klein"),
        H.point(QQ(1) / 2, 0, model="klein"),
        H.point(0, QQ(1) / 2, model="klein"),
    ]
)
P
```

A point prints in the upper half plane model when its coordinates there lie
in the base ring, as the origin of the Klein model, `I`, and by its Klein
coordinates otherwise. The Klein coordinates can always be read back:

```{code-cell}
[v.coordinates(model="klein") for v in P.vertices()]
```

Angles are measured in multiples of $2\pi$, so that a right angle is `1/4`,
and the area in units of $2\pi$. The angles of this triangle are not
rational multiples of $2\pi$, so that they are only available numerically:

```{code-cell}
P.angles(numerical=True)
```

```{code-cell}
P.area(numerical=True)
```

A side of length $\ell$ is described by $\cosh^2 \ell$, which lies in the base
ring even when $\cosh \ell$ does not:

```{code-cell}
[P.edge_cosh_squared(i) for i in range(3)]
```

The generators of `hyperbolic_polygons` build polygons from their angles and
from the hyperbolic cosine of some of their sides. The base ring is the number
field generated by the Klein coordinates of the vertices, except for a
triangle, which lies in the plane of its invariant quadratic form, over the
invariant trace field of its triangle group. A triangle with angles
$\pi/2, \pi/6, \pi/6$:

```{code-cell}
from flatsurf import hyperbolic_polygons

T = hyperbolic_polygons.triangle(QQ(1) / 4, QQ(1) / 12, QQ(1) / 12)
T.base_ring()
```

```{code-cell}
T.angles(), T.area()
```

The regular octagon with angles $\pi/4$:

```{code-cell}
O = hyperbolic_polygons.regular_ngon(8, QQ(1) / 8)
O.base_ring()
```

```{code-cell}
O.angles(), O.area()
```

A right-angled hexagon, given the hyperbolic cosines of its edges 1, 3 and 5;
this one has rational vertices:

```{code-cell}
X = hyperbolic_polygons.right_angled_hexagon(QQ(5) / 4, QQ(5) / 4, QQ(145) / 24)
X.base_ring()
```

```{code-cell}
X.angles(), [X.edge_cosh_squared(i) for i in range(6)]
```

## The base ring

The regular octagon with angles $\pi/4$, its opposite sides glued, is a
closed surface of genus 2:

```{code-cell}
from flatsurf import hyperbolic_surfaces

S = hyperbolic_surfaces.regular_octagon()
S
```

Its base ring holds the Klein coordinates of the vertices and every side
pairing; every gluing of a hyperbolic surface is checked to be an isometry
defined over its base ring, so that a gluing that needs a larger field is
refused:

```{code-cell}
S.base_ring()
```

## Holonomy and trace field

The fundamental group of the surface is generated by closed walks that start
in the polygon 0 and cross its edges; the walk `0 --i-- 0` crosses the edge
`i`:

```{code-cell}
S.fundamental_group().gens()
```

The holonomy representation is defined on the fundamental group of the
surface punctured at its vertices. It sends a walk to the isometry of the
hyperbolic plane obtained by developing the polygons along it, a matrix of
$\mathrm{SO}(2, 1)$ acting on the Klein coordinates $(x, y, 1)$:

```{code-cell}
rho = S.holonomy_representation()
rho.domain()
```

```{code-cell}
g = rho(rho.domain().gens()[0])
g
```

```{code-cell}
g.trace()
```

The invariant trace field of the representation is $\mathbb{Q}(\sqrt{2})$,
smaller than the base ring:

```{code-cell}
rho.invariant_trace_field()
```

## Pants and boundary traces

A pair of pants with geodesic boundary components, each given by the trace
$t = 1 + 2 \cosh \ell$ of its holonomy in $\mathrm{SO}(2, 1)$, where $\ell$ is
its length:

```{code-cell}
pants = hyperbolic_surfaces.pants(boundary_traces=(15, 15, 15))
pants
```

```{code-cell}
pants.signature()
```

```{code-cell}
pants.boundary_components()
```

## Signatures

A signature is topological: the genus, the orders $k_i$ of the cone points of
angles $2\pi(1 + k_i)$, the number of cusps, and the traces of the boundary
components. Its Euler characteristic ignores the cone points; its divisor
Euler characteristic $\chi(S, \beta) = 2 - 2g - c - b + \sum k_i$ counts
them:

```{code-cell}
from flatsurf import SurfaceSignature

s = SurfaceSignature(g=1, cone_orders=(QQ(-1) / 2,), boundary_traces=(15,))
s
```

```{code-cell}
s.euler_characteristic(), s.divisor_euler_characteristic()
```

A signature can also be given as an orbifold, by its genus and the orders $m$
of its orbifold points, of angles $2\pi/m$, and read back as such, with the
number of cusps last:

```{code-cell}
s = SurfaceSignature.from_orbifold_orders(0, (2, 4, 5))
s
```

```{code-cell}
s.orbifold_orders()
```

The genus 2 octagon has no cone point. By the Gauss-Bonnet formula, the area
of a hyperbolic surface in units of $2\pi$ is the opposite of the divisor
Euler characteristic of its signature:

```{code-cell}
S.signature()
```

```{code-cell}
S.area(), S.signature().divisor_euler_characteristic()
```

`hyperbolic_surfaces.from_signature` builds a surface with a given signature,
here a closed surface of genus 2 over the rationals:

```{code-cell}
S = hyperbolic_surfaces.from_signature(SurfaceSignature(g=2))
S
```

```{code-cell}
S.base_ring(), S.signature()
```

## Subgroups of triangle groups

The triangle group with periods $(p, q, r)$ is generated by the rotations
about the vertices of a triangle with angles $\pi/p, \pi/r, \pi/q$, and its
images tile the hyperbolic plane. The tiling is unfolded about the vertex of
period $p$, placed at the origin: the $p$ copies of the triangle under the
rotation of order $p$ and of its mirror image form a polygon with $2p$ sides.
Each side is glued to another by an element of the triangle group, so that the
holonomy of the surface obtained is a subgroup of the group, of index $p$ when
the surface is an orbifold. The gluing pairs the side $2k$ with the side
$2\sigma(k) + 1$, for a permutation $\sigma$ of $0, \ldots, p - 1$; the sides
$2k$ and $2j$ cannot be glued, as the tiling would not be preserved:

```{code-cell}
from sage.all import QQ

from flatsurf import fuchsian_groups, hyperbolic_polygons
from flatsurf.geometry.hyperbolic_surface import MutableOrientedHyperbolicSurface


def unfolded(p, q, r, sigma):
    G = fuchsian_groups.triangle(p, q, r)
    T = hyperbolic_polygons.triangle(QQ(1) / (2 * p), QQ(1) / (2 * r), QQ(1) / (2 * q))
    g = G.gens()[0]
    _, v1, v2 = T.vertices()
    vertices = []
    for k in range(p):
        vertices += [v1, v2]
        v1, v2 = g(v1), g(v2)
    P = T.parent().polygon(vertices=vertices)
    S = MutableOrientedHyperbolicSurface(P.parent())
    S.add_polygon(P)
    for k, j in enumerate(sigma):
        S.glue((0, 2 * k), (0, 2 * j + 1))
    S.set_immutable()
    return G, T, P, S
```

With periods $(8, 2, 8)$ and opposite sides glued:

```{code-cell}
G, T, P, S = unfolded(8, 2, 8, [4, 5, 6, 7, 0, 1, 2, 3])
G
```

```{code-cell}
P.angles()
```

The area of the polygon is $2p = 16$ times that of the triangle:

```{code-cell}
P.area(), 16 * T.area()
```

```{code-cell}
S
```

```{code-cell}
S.signature(), S.is_orbifold()
```

This is a surface of genus 2 over $\mathbb{Q}(\sqrt{2})$, while the regular
octagon is defined over a field of degree 4:

```{code-cell}
S.base_ring()
```

```{code-cell}
hyperbolic_surfaces.regular_octagon().base_ring()
```

The invariant trace field of the surface is that of the triangle group:

```{code-cell}
S.holonomy_representation().invariant_trace_field()
```

```{code-cell}
G.invariant_trace_field()
```

Another permutation, with periods $(4, 3, 3)$, gives a surface with cone
points whose angles are not $2\pi/m$, so that it is no orbifold. Its area
is still $2p$ times that of the triangle, and its invariant trace field is
still that of the triangle group:

```{code-cell}
G, T, P, S = unfolded(4, 3, 3, [1, 2, 3, 0])
S.signature(), S.is_orbifold()
```

```{code-cell}
P.area(), 8 * T.area()
```

```{code-cell}
S.holonomy_representation().invariant_trace_field()
```
