**Added:**

* Added an optional ``label`` argument to ``representative()`` of points of surfaces, to get a representative of the point in a given polygon.

* Added an action of similarities on vectors, i.e., ``g * v`` now applies the similarity ``g`` to the vector ``v`` in the same way as ``g(v)``.

**Changed:**

* Changed the image of a vector under a similarity ``g(v)`` to be an immutable vector.
